# 지글지글 한 판

한국식 고깃집 숯불 위에서 고기를 굽고, 손님을 받아 랭킹에 도전하는 3D 웹 게임.

- 게임 화면: `index.html` (GitHub Pages로 배포, three.js r128)
- 랭킹 서버: Supabase 프로젝트 `gogi-grill` (서울 리전)
  - Edge Function `game` (`supabase-game-function.ts`)
  - 테이블: `runs`(게임 한 판), `scores`(시즌별 개인 최고 기록) — `supabase-migration.sql`

## 랭킹 규칙

- 시즌: 매월 1일 0시(한국 시간)에 초기화. 시즌 키는 서버 시간으로 계산.
- 점수는 서버가 서빙 기록(시간, 주문 종류, 잘 구운 조각 수, 손님 대기 비율)으로 다시 계산. 클라이언트가 보낸 합계는 저장하지 않음.
- 한 판은 한 번만 제출 가능(조건부 상태 변경으로 중복 차단).
- 실제 경과 시간 170초 미만, 30분 초과, 지난 시즌에 시작한 판, 비정상적으로 많은 서빙은 거절.
- 새로 시작하거나 탭을 닫으면 진행 중이던 판은 포기 처리.
- 랭킹 표는 누구나 읽기만 가능, 쓰기는 Edge Function만 가능(RLS).
